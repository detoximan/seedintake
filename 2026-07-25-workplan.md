# План рефакторинга Link Worker (SeedIntake)
Дата создания: 2026-07-25
Статус: В работе

## Цель проекта
Перестроить обработку ссылок в соцсетях (Instagram, TikTok, YouTube, Facebook, Threads) с монолитного процессора на архитектуру **URL Router + Узкоспециализированные Воркеры**.

## Ключевые требования к обработке контента
1. **Видео / Reels / Shorts / TikTok Video:**
   - Скачивание видео/аудио поток.
   - Извлечение аудио (ffmpeg) и транскрибация через Groq (Whisper).
   - Извлечение текста из описания поста.

2. **Карусели / Одиночные фото / Слайдшоу (Instagram Carousel, TikTok Photo, Facebook Post):**
   - Скачивание всех изображений галереи/поста.
   - Прогон через OCR (Tesseract / pytesseract) для извлечения текста с картинок.
   - Дедупликация и очистка текстов (убирать подмножества, дубли и служебный мусор).
   - Извлечение текста описания под постом.

3. **Стабильная авторизация (Instagram / TikTok):**
   - Отказ от динамического считывания куков из открытого браузера Firefox через `browser_cookie3` (блокирует файл БД при запущенном браузере).
   - Использование статического файла куков (`.cookies/instagram.txt`) или сохранённой сессии Instaloader.

4. **Быстрый маршрутизатор (URL Router):**
   - Мгновенная классификация ссылок без лишниx попыток загрузки не подходящими утилитами.
