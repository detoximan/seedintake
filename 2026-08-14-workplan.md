# План работ SeedIntake
Дата обновления: 2026-08-14
Статус: В работе

## 🎯 Главная цель
Обеспечить 100% надёжное, безошибочное извлечение контента из социальных сетей (Reels, Shorts, TikTok, Instagram-карусели, фото-слайды, видео с наложенным текстом, посты) без создания пустых записей-«пустышек» в Google Sheets, с автоматическим использованием куков и качественным двуязычным оформлением сидов.

---

## 📋 Задачи

### Задача 1: Аудит и доработка процессоров контента
1. **Автообновление утилит:** перед запуском тихо обновлять `yt-dlp` и `gallery-dl`.
2. **Куки сразу и везде:** куки из `.cookies/` (`instagram.txt`, `tiktok.txt`, `youtube.txt`, `cookies.txt`) передаются в `yt-dlp`, `gallery-dl`, `instaloader` сразу с первого вызова.
3. **Железная воронка контента:**
   - **Короткие видео (Reels / Shorts / TikTok):**
     1. Скачивание видео/аудио с куками.
     2. Whisper-транскрибация речи.
     3. Если речи нет (музыка/тишина/пусто) → покадровый OCR через `ffmpeg` + `tesseract`.
     4. Извлечение описания (caption/text).
   - **Фото-карусели / TikTok фото-слайды:**
     1. Скачивание всех слайдов (`gallery-dl` / `instaloader`).
     2. OCR по каждому слайду с дедупликацией.
     3. Извлечение текста описания.
   - **Смешанные карусели:**
     1. Обработка каждого слайда по типу (фото → OCR, видео → речь/OCR).
4. **Защита от пустышек в `worker.py`:**
   - Устранить баг, когда непустые `views`/`likes` пропускали сид с пустым материалом (`нет`, `нет`, `нет`) в Google Таблицу.
   - Никаких пустых строк в Google Таблице!

### Задача 2: Исправление старых ссылок на GitHub в Google Sheets
- Проверить все строки в Google Sheets.
- Заменить устаревшие ссылки (со старого пути репозитория `Detoximan`) на актуальные URL в `https://github.com/detoximan/seedintake/blob/main/Inbox/YYYY/full/...`.

### Задача 3: Тестовая обработка новыми партиями (по 5 ссылок)
- Брать новые ссылки порциями по 5 штук.
- Проверять качество распознавания речи, OCR, описаний и переводов.
- Валидация перед записью в Google Sheets.

### Задача 4: Финальная чистка
- В самом конце, после проверки и стабилизации, аккуратно удалить временные и устаревшие скрипты.
