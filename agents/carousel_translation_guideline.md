# Регламент по-слайдового перевода каруселей 1-в-1

## 1. Контекст проблемы
При обработке Instagram/TikTok каруселей контент представляет собой серию изображений (слайдов) с текстом: `[01_image.jpg]: Текст слайда 1`, `[02_image.jpg]: Текст слайда 2` и т.д.
Ранее при попытке автоматического пакетного перевода через внешние API происходила потеря слайдов, суммаризация или обрезка перевода на середине.

## 2. Железные правила
1. **Строгий запрет внешних API перевода:**
   - Groq API используется **исключительно** для транскрибации Whisper (`GroqAudioTranscriber`).
   - Запрещено вызывать внешние сервисы перевода (Google Translate API, Groq LLM и др.) для текстового контента.
   - **Перевод выполняет сам агент в контексте диалога.**
2. **Структура 1-в-1:**
   - Для каждого слайда `[файл.jpg]: оригинал` в блоке перевода должен быть соответствующий слайд `[файл.jpg]: русский перевод`.
   - Запрещено объединять слайды, обобщать текст, выкидывать имена файлов или сокращать смысл.
3. **Двуязычный формат:**
   ```text
   [Оригинальный текст с разметкой слайдов]

   ====================

   [Полный русский перевод с сохранением разметки слайдов]
   ```
4. **Атомарная синхронизация:**
   - Для применения перевода используется скрипт:
     ```bash
     python3 services/seed_pipeline/apply_bilingual_sync.py <seed_id> --translation-file <путь_к_файлу_с_переводом>
     ```
   - Скрипт синхронно обновляет `Inbox/2026/slim/<seed_id>-s.md`, `Inbox/2026/full/<seed_id>-f.md` и колонку `E` в Google Sheets.
5. **Валидация качества:**
   - Для проверки полноты переводов запускается:
     ```bash
     python3 services/seed_pipeline/audit_translations.py
     ```
   - Ошибок в отчёте аудита быть не должно (0 проблемных записей).
